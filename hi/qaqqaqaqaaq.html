“Qaqqaqaqaaq” का क्या मतलब है?

मेरा Github username Kalaallisut [kalaːɬːisʉt] (वेस्ट ग्रीनलैंडिक) भाषा का एक शब्द है। यह एक polysynthetic भाषा है — इसमें कई morphemes जोड़कर शब्द बनते हैं, जिससे ऐसे ‘sentence-words’ बन जाते हैं जैसे:

Qaqqa-qa-qaaq
पहाड़हैemph.3.ind
‘वहाँ बहुत सारे पहाड़ हैं’
यह बनता कैसे है? -qar- जैसे suffixes से पहले qaqqaq अपना आख़िरी -q छोड़ देता है। फिर -qi- suffix से पहले -qar- अपना आख़िरी -r- छोड़ देता है, और -voq के साथ मिलकर इसका एक आम छोटा रूप -qaaq बन जाता है।

यह मेरा Github username क्यों है? उस वक़्त आसान लगा था, और मैं भी ऐसी जगह से हूँ जहाँ बहुत सारे पहाड़ हैं!
